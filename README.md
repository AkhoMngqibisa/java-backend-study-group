# Java & Backend Engineering Study Group

Welcome to our Java & Backend Engineering Study Group.

The purpose of this repository is to document our weekly knowledge-sharing sessions, store practical Java examples, and provide exercises that help us build a strong foundation in Java and backend engineering.

## Study Format

We meet once a week for approximately **1 hour and 30 minutes**.

Each session follows this structure:

* **10 minutes** — Review previous lesson
* **25 minutes** — Theory
* **35 minutes** — Live coding
* **15 minutes** — Discussion and questions
* **5 minutes** — Assignment / challenge

## Project

Throughout the study programme, we will build a backend application and continuously improve it as we learn new concepts.

The project will eventually incorporate:

Java → Spring Boot → REST API → Database → JPA/Hibernate → Testing → Security → Docker → CI/CD → Advanced Architecture

## Learning Philosophy

The goal is not simply to complete tutorials.

For every topic, we want to understand:

1. **What is it?**
2. **Why does it exist?**
3. **How does it work?**
4. **When should we use it?**
5. **What are the alternatives?**
6. **What are the trade-offs?**
7. **How is it used in real backend systems?**

## Resources

The repository will contain our own notes, examples, exercises and useful references.
